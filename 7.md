# Experiment 7

## Aim

Implementation of RNN model for Stock Price Prediction in Python.

## Description

Long Short-Term Memory (LSTM) networks are a type of Recurrent Neural Network (RNN) designed to model sequential and time-dependent data. Unlike traditional neural networks, LSTMs can retain information over long periods using memory cells and gating mechanisms, making them highly effective for time series forecasting tasks such as stock price prediction.

In this experiment, we apply an LSTM-based deep learning model to predict stock prices using historical data. The dataset is obtained from Yahoo Finance for Apple Inc. (AAPL), which includes daily closing prices. The model learns patterns and trends from past stock prices and attempts to forecast future values.

The architecture consists of stacked LSTM layers with dropout regularization to prevent overfitting, followed by dense layers to produce the final prediction. The input data is preprocessed using normalization and converted into sequences of fixed time steps. The model is trained to minimize prediction error and is evaluated by comparing actual and predicted prices visually.

## Algorithm

1. Import libraries such as yfinance, NumPy, Pandas, Matplotlib, MinMaxScaler, and TensorFlow/Keras modules.
2. Download historical stock data for Apple Inc. using yfinance.
3. Extract the Close price column for prediction.
4. Normalize the data using MinMaxScaler to scale values between 0 and 1.
5. Plot the closing price to understand trends.
6. Set a time step window, such as 60 days, for sequence creation.
7. Create input sequences and corresponding output values using past 60 days data.
8. Convert input data into 3D shape: samples, time steps, and features.
9. Add LSTM layers for sequence learning.
10. Use Dropout layers for regularization.
11. Add Dense layers for final output.
12. Compile using Adam optimizer and mean squared error loss function.
13. Train the model on the prepared dataset with specified epochs and batch size.
14. Use the trained model to predict stock prices for the entire dataset.
15. Convert predicted values back to original scale using the scaler.
16. Plot actual vs predicted prices for comparison.
17. Use the last 60 days of data to predict the next day's stock price.

## Code

```python
import yfinance as yf
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.preprocessing import MinMaxScaler
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense, Dropout

ticker = "AAPL"
df = yf.download(ticker, start="2015-01-01", end="2024-12-31")
data = df[["Close"]]

scaler = MinMaxScaler(feature_range=(0, 1))
scaled_data = scaler.fit_transform(data.values)

plt.figure(figsize=(12, 6))
plt.plot(data["Close"])
plt.title("Apple Stock Price History")
plt.ylabel("Price USD ($)")
plt.show()

window_size = 60
train_len = len(scaled_data) * 0.8
train_data = scaled_data[0 : int(train_len), :]

x_train, y_train = [], []

for i in range(window_size, len(train_data)):
    x_train.append(train_data[i - window_size : i, 0])
    y_train.append(train_data[i, 0])

x_train, y_train = np.array(x_train), np.array(y_train)
x_train = np.reshape(x_train, (x_train.shape[0], x_train.shape[1], 1))

model = Sequential(
    [
        LSTM(50, return_sequences=True, input_shape=(x_train.shape[1], 1)),
        Dropout(0.2),
        LSTM(50, return_sequences=False),
        Dropout(0.2),
        Dense(25),
        Dense(1),
    ]
)

model.compile(optimizer="adam", loss="mean_squared_error")
model.fit(x_train, y_train, batch_size=32, epochs=10)

x_all = []

for i in range(window_size, len(scaled_data)):
    x_all.append(scaled_data[i - window_size : i, 0])

x_all = np.array(x_all)
x_all = np.reshape(x_all, (x_all.shape[0], x_all.shape[1], 1))

all_predictions = model.predict(x_all)
all_predictions = scaler.inverse_transform(all_predictions)

predicted_plot = np.empty_like(data.values)
predicted_plot[:, :] = np.nan
predicted_plot[window_size:] = all_predictions

plt.figure(figsize=(16, 8))
plt.title("LSTM Model - Apple Stock Price Prediction (Entire Dataset)")
plt.xlabel("Date")
plt.ylabel("Close Price USD ($)")
plt.plot(data.index, data.values, label="Actual Price", color="blue")
plt.plot(data.index, predicted_plot, label="Model Prediction", color="orange", alpha=0.8)
plt.legend(loc="lower right")
plt.show()

last_60_days = scaled_data[-60:]
last_60_days_reshaped = last_60_days.reshape(1, 60, 1)

predicted_scaled_price = model.predict(last_60_days_reshaped)
predicted_price = scaler.inverse_transform(predicted_scaled_price)
last_actual_price = scaler.inverse_transform(scaled_data[-1].reshape(-1, 1))

print(f"Actual Price (Last Day in Data): ${last_actual_price[0][0]:.2f}")
print(f"Predicted Price for the Next Day: ${predicted_price[0][0]:.2f}")
```
