# Experiment 6

## Aim

Improving Autoencoder's Performance using convolution layers in Python.

## Description

Convolutional Autoencoders (CAE) are a variant of autoencoders that use convolutional layers to extract features, especially suitable for image data. Unlike traditional fully connected autoencoders, CAEs preserve the spatial structure of the input, making them more efficient for image reconstruction tasks. In this experiment, we will apply a Convolutional Autoencoder on the MNIST dataset, which consists of 28x28 pixel images of handwritten digits.

The architecture of the Convolutional Autoencoder is built with convolutional and pooling layers for the encoder, and upsampling and convolutional layers for the decoder. The goal of this experiment is to train the model to compress the images of handwritten digits into a lower-dimensional latent space, and then reconstruct the images as accurately as possible. We will visualize both the original and reconstructed images to evaluate the performance of the model.

## Algorithm

1. Import required libraries such as TensorFlow, NumPy, and Matplotlib.
2. Load the MNIST dataset, which consists of images of handwritten digits.
3. Normalize the images by dividing pixel values by 255 to scale them to the [0, 1] range.
4. Reshape the data into 28x28x1 format to be compatible with convolutional operations.
5. Define the Convolutional Autoencoder.
6. Use Conv2D layers for feature extraction in the encoder, followed by MaxPooling2D for downsampling.
7. Capture the latent representation at the bottleneck in a compact form.
8. Use Conv2D layers followed by UpSampling2D in the decoder to reconstruct the image.
9. Compile the model using the Adam optimizer and binary crossentropy loss function.
10. Train the model using the MNIST images as both input and output.
11. Predict the reconstructed images after training.
12. Display both the original and reconstructed images side by side.

## Code

```python
import numpy as np
import matplotlib.pyplot as plt
from tensorflow.keras.datasets import mnist
from tensorflow.keras.models import Model
from tensorflow.keras.layers import Input, Conv2D, MaxPooling2D, UpSampling2D
from tensorflow.keras.optimizers import Adam

# Load and preprocess the MNIST dataset
(x_train, _), (x_test, _) = mnist.load_data()
x_train = x_train.astype("float32") / 255.0
x_test = x_test.astype("float32") / 255.0
x_train = np.reshape(x_train, (len(x_train), 28, 28, 1))
x_test = np.reshape(x_test, (len(x_test), 28, 28, 1))

# Define the Convolutional Autoencoder model
input_img = Input(shape=(28, 28, 1))

# Encoder
x = Conv2D(32, (3, 3), activation="relu", padding="same")(input_img)
x = MaxPooling2D((2, 2), padding="same")(x)
x = Conv2D(32, (3, 3), activation="relu", padding="same")(x)
encoded = MaxPooling2D((2, 2), padding="same")(x)

# Decoder
x = Conv2D(32, (3, 3), activation="relu", padding="same")(encoded)
x = UpSampling2D((2, 2))(x)
x = Conv2D(32, (3, 3), activation="relu", padding="same")(x)
x = UpSampling2D((2, 2))(x)
decoded = Conv2D(1, (3, 3), activation="sigmoid", padding="same")(x)

# Create the autoencoder model
autoencoder = Model(input_img, decoded)

# Compile the model
autoencoder.compile(optimizer=Adam(), loss="binary_crossentropy")

# Summary of the model
autoencoder.summary()

# Train the model
autoencoder.fit(
    x_train,
    x_train,
    epochs=10,
    shuffle=True,
    validation_data=(x_test, x_test),
)

# Predict the reconstructed images
decoded_imgs = autoencoder.predict(x_test)

# Display the original and reconstructed images
n = 10
plt.figure(figsize=(20, 4))

for i in range(n):
    ax = plt.subplot(2, n, i + 1)
    plt.imshow(x_test[i].reshape(28, 28), cmap="gray")
    plt.axis("off")

    ax = plt.subplot(2, n, i + 1 + n)
    plt.imshow(decoded_imgs[i].reshape(28, 28), cmap="gray")
    plt.axis("off")

plt.show()
```
