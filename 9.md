# Experiment 9

## Aim

Implementation of transfer learning using the pre-trained model MobileNetV2 for image classification in Python.

## Description

MobileNetV2 is a lightweight and efficient Convolutional Neural Network (CNN) architecture designed for mobile and resource-constrained environments. It uses depthwise separable convolutions and inverted residual blocks to significantly reduce computational cost while maintaining strong performance. In deep learning tasks where hardware limitations such as GPU memory are a concern, MobileNetV2 serves as an excellent choice for transfer learning.

In this experiment, MobileNetV2 pre-trained on the ImageNet dataset is applied to the CIFAR-10 image classification task. To optimize memory usage and prevent out-of-memory issues, only a subset of the dataset is used, and GPU memory growth is enabled. Additionally, instead of loading the entire dataset into memory, a tf.data pipeline is utilized for efficient data loading, preprocessing, and batching.

The images are resized to 96x96 pixels to match the input requirements of MobileNetV2 and normalized to improve model convergence. Labels are converted into one-hot encoded vectors. The pre-trained MobileNetV2 model is loaded without its top layers, and all its base layers are initially frozen to preserve learned features. A custom classification head is added using Global Average Pooling, Dense, and Dropout layers to perform classification on CIFAR-10 classes.

The model is first trained in a feature extraction phase, where only the custom layers are updated. After this, fine-tuning is performed by unfreezing the last few layers of the base model, allowing the network to adapt high-level features to the new dataset. A lower learning rate is used during fine-tuning to ensure stable learning. Finally, the model is evaluated on test data, and performance is visualized using accuracy and loss plots. Sample predictions are also displayed to assess classification results visually.

## Algorithm

1. Import required libraries for deep learning, data processing, and visualization.
2. Enable GPU memory growth to avoid out-of-memory issues.
3. Load CIFAR-10 dataset and reduce its size for memory efficiency.
4. Normalize images, resize to required dimensions, and one-hot encode labels.
5. Use tf.data API for efficient data loading, batching, shuffling, and prefetching.
6. Delete unused raw data and perform garbage collection.
7. Load MobileNetV2 without top layers and freeze base layers.
8. Add GlobalAveragePooling, Dense, and Dropout layers for classification.
9. Compile using Adam optimizer with categorical cross-entropy loss.
10. Train model using feature extraction approach.
11. Unfreeze last layers of base model and recompile with lower learning rate.
12. Train again to fine-tune high-level features.
13. Evaluate model performance on test dataset.
14. Plot training and validation accuracy and loss curves.
15. Predict classes on sample images and compare with true labels.

## Code

```python
import numpy as np
import matplotlib.pyplot as plt
import tensorflow as tf
from tensorflow.keras.applications import MobileNetV2
from tensorflow.keras.layers import Dense, GlobalAveragePooling2D, Dropout
from tensorflow.keras.models import Model
from tensorflow.keras.optimizers import Adam
from tensorflow.keras.datasets import cifar10
from tensorflow.keras.utils import to_categorical
import gc

# GPU memory growth prevents OOM on Colab/Kaggle.
gpus = tf.config.list_physical_devices("GPU")
if gpus:
    for gpu in gpus:
        tf.config.experimental.set_memory_growth(gpu, True)

# Load only a subset to save RAM.
(x_train, y_train), (x_test, y_test) = cifar10.load_data()
x_train, y_train = x_train[:15000], y_train[:15000]
x_test, y_test = x_test[:2000], y_test[:2000]

class_names = [
    "airplane",
    "automobile",
    "bird",
    "cat",
    "deer",
    "dog",
    "frog",
    "horse",
    "ship",
    "truck",
]

# Use tf.data pipeline instead of loading everything into RAM.
IMG_SIZE = 96
BATCH_SIZE = 16
AUTOTUNE = tf.data.AUTOTUNE


def preprocess(img, label):
    img = tf.cast(img, tf.float32) / 255.0
    img = tf.image.resize(img, [IMG_SIZE, IMG_SIZE])
    label = tf.one_hot(tf.squeeze(label), 10)
    return img, label


train_ds = (
    tf.data.Dataset.from_tensor_slices((x_train, y_train))
    .map(preprocess, num_parallel_calls=AUTOTUNE)
    .cache()
    .shuffle(1000)
    .batch(BATCH_SIZE)
    .prefetch(AUTOTUNE)
)

test_ds = (
    tf.data.Dataset.from_tensor_slices((x_test, y_test))
    .map(preprocess, num_parallel_calls=AUTOTUNE)
    .batch(BATCH_SIZE)
    .prefetch(AUTOTUNE)
)

# Free raw arrays because they are no longer needed.
del x_train, x_test
gc.collect()

# Build model.
base_model = MobileNetV2(
    weights="imagenet",
    include_top=False,
    input_shape=(IMG_SIZE, IMG_SIZE, 3),
)
base_model.trainable = False

x = base_model.output
x = GlobalAveragePooling2D()(x)
x = Dense(128, activation="relu")(x)
x = Dropout(0.3)(x)
output = Dense(10, activation="softmax")(x)

model = Model(inputs=base_model.input, outputs=output)
model.compile(
    optimizer=Adam(1e-3),
    loss="categorical_crossentropy",
    metrics=["accuracy"],
)
model.summary()

# Phase 1: feature extraction.
history = model.fit(train_ds, epochs=10, validation_data=test_ds, verbose=1)

# Phase 2: fine-tuning by unfreezing last 30 layers.
base_model.trainable = True
for layer in base_model.layers[:-30]:
    layer.trainable = False

model.compile(
    optimizer=Adam(1e-5),
    loss="categorical_crossentropy",
    metrics=["accuracy"],
)
history_ft = model.fit(train_ds, epochs=10, validation_data=test_ds, verbose=1)

# Evaluate.
loss, acc = model.evaluate(test_ds, verbose=0)
print(f"\nTest Accuracy: {acc * 100:.2f}%")

# Plot.
all_acc = history.history["accuracy"] + history_ft.history["accuracy"]
all_val = history.history["val_accuracy"] + history_ft.history["val_accuracy"]
all_loss = history.history["loss"] + history_ft.history["loss"]
all_vloss = history.history["val_loss"] + history_ft.history["val_loss"]

fig, axes = plt.subplots(1, 2, figsize=(12, 4))
axes[0].plot(all_acc, label="Train")
axes[0].plot(all_val, label="Val")
axes[0].set_title("MobileNetV2 - Accuracy")
axes[0].legend()
axes[1].plot(all_loss, label="Train")
axes[1].plot(all_vloss, label="Val")
axes[1].set_title("MobileNetV2 - Loss")
axes[1].legend()
plt.tight_layout()
plt.show()

# Sample predictions from one batch in the pipeline.
sample_imgs, sample_labels = next(iter(test_ds.take(1)))
preds = model.predict(sample_imgs[:10])

fig, axes = plt.subplots(2, 5, figsize=(14, 5))
for i, ax in enumerate(axes.flat):
    ax.imshow(sample_imgs[i].numpy())
    pred = class_names[np.argmax(preds[i])]
    true = class_names[np.argmax(sample_labels[i].numpy())]
    ax.set_title(
        f"P: {pred}\nT: {true}",
        color="green" if pred == true else "red",
        fontsize=8,
    )
    ax.axis("off")

plt.suptitle("MobileNetV2 Predictions")
plt.tight_layout()
plt.show()
```
