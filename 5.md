## Aim

Application of Autoencoders on Image Dataset.

## Description

Autoencoders are a class of Artificial Neural Networks (ANNs) used for unsupervised learning and dimensionality reduction. They are designed to learn efficient representations of input data by compressing the data into a lower-dimensional space and then reconstructing it back to its original form.

Unlike traditional dimensionality reduction techniques such as Principal Component Analysis (PCA), autoencoders can capture non-linear relationships within the data using multiple hidden layers and activation functions. In this implementation, a Deep Stacked Autoencoder is used, where multiple layers are stacked to progressively extract more abstract features from the MNIST handwritten digit dataset.

An autoencoder consists of three main components: encoder, bottleneck layer, and decoder.

The encoder in this model uses a hierarchical structure of 784 -> 128 -> 64 to compress the high-dimensional input data. The bottleneck layer with 32 neurons contains the compressed latent representation that captures the most vital structural information of the digit. The decoder structure 64 -> 128 -> 784 reconstructs the original image from this 32-dimensional vector.

This model is also applied to denoising, where it learns to ignore random Gaussian noise and recover the underlying digit structure, demonstrating the model's ability to prioritize essential information over data corruption.

## Algorithm

1. Import required libraries such as NumPy, Pandas, TensorFlow, and Keras.
2. Load the dataset (MNIST) and perform preprocessing steps such as normalization by dividing by 255.0.
3. Convert the dataset into flattened 1D NumPy arrays of size 784 for neural network compatibility.
4. Split the dataset into training and testing sets to evaluate generalization.
5. Define the encoder using multiple Dense layers with 128 and 64 neurons using ReLU activation to gradually decrease dimensionality.
6. Add a bottleneck layer with 32 neurons to represent the most compressed features.
7. Define the decoder using Dense layers with increasing neurons, 64 and 128, to mirror the encoder and reconstruct the input.
8. Combine encoder and decoder to build the full Deep Autoencoder model.
9. Compile the model using the Adam optimizer and Mean Squared Error (MSE) loss function.
10. Train the model using the clean input data as both input and target output.
11. Inject Gaussian noise into the dataset and re-train/compile to perform denoising.
12. Obtain compressed and reconstructed features from the model to visualize the results.
13. Evaluate reconstruction performance by plotting original, noisy, and reconstructed images using Matplotlib.

## Code

```python
import tensorflow as tf
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

from tensorflow.keras import layers, datasets, models

(x_train, _), (x_test, _) = datasets.mnist.load_data()

x_train = x_train / 255.0
x_test = x_test / 255.0

x_train = x_train.reshape(len(x_train), 784)
x_test = x_test.reshape(len(x_test), 784)

x_train.shape

input_dim = 784
encoding_dim = 32

input_img = layers.Input(shape=(input_dim,))
encoded = layers.Dense(128, activation="relu")(input_img)
encoded = layers.Dense(64, activation="relu")(encoded)
bottleneck = layers.Dense(encoding_dim, activation="relu")(encoded)
decoded = layers.Dense(64, activation="relu")(bottleneck)
decoded = layers.Dense(128, activation="relu")(decoded)
output = layers.Dense(input_dim, activation="sigmoid")(decoded)

autoencoder = models.Model(input_img, output)
autoencoder.compile(optimizer="adam", loss="mse")
autoencoder.summary()

history = autoencoder.fit(
    x_train,
    x_train,
    epochs=25,
    batch_size=256,
    shuffle=True,
    validation_data=(x_test, x_test),
    verbose=1,
)

decoded_img = autoencoder.predict(x_test)

n = 10
plt.figure(figsize=(20, 4))

for i in range(n):
    ax = plt.subplot(2, n, i + 1)
    plt.imshow(x_test[i].reshape(28, 28), cmap="gray")
    plt.title("Original")
    plt.axis("off")

    ax = plt.subplot(2, n, i + 1 + n)
    plt.imshow(decoded_img[i].reshape(28, 28), cmap="gray")
    plt.title("Reconstructed")
    plt.axis("off")

plt.show()

noise_factor = 0.5
x_train_noisy = x_train + noise_factor * np.random.normal(size=x_train.shape)
x_test_noisy = x_test + noise_factor * np.random.normal(size=x_test.shape)

x_train_noisy = np.clip(x_train_noisy, 0, 1)
x_test_noisy = np.clip(x_test_noisy, 0, 1)

autoencoder.compile(optimizer="adam", loss="mse")
autoencoder.fit(
    x_train_noisy,
    x_train_noisy,
    epochs=25,
    batch_size=256,
    shuffle=True,
    validation_data=(x_test_noisy, x_test_noisy),
    verbose=1,
)

decoded_img_noisy = autoencoder.predict(x_test_noisy)

n = 10
plt.figure(figsize=(20, 6))

for i in range(n):
    ax = plt.subplot(3, n, i + 1)
    plt.imshow(x_test_noisy[i].reshape(28, 28), cmap="gray")
    plt.title("Noisy Image")
    plt.axis("off")

    ax = plt.subplot(3, n, i + 1 + n)
    plt.imshow(x_test[i].reshape(28, 28), cmap="gray")
    plt.title("Original Image")
    plt.axis("off")

    ax = plt.subplot(3, n, i + 1 + 2 * n)
    plt.imshow(decoded_img_noisy[i].reshape(28, 28), cmap="gray")
    plt.title("Reconstructed")
    plt.axis("off")

plt.tight_layout()
plt.show()
```
