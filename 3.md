## Aim

Implementation of Convolution Neural Network for MRI Data Set in Python.

## Description

Convolutional Neural Networks (CNNs) are a specialized class of deep learning models designed to process image data. Unlike traditional Artificial Neural Networks, CNNs automatically extract spatial and hierarchical features from images using convolution operations, making them highly effective for medical image analysis such as MRI-based tumor detection.

In this implementation, a CNN model is applied to an MRI brain image dataset to classify images into tumor and non-tumor categories using Python and TensorFlow/Keras.

A CNN consists of the following main components: input layer, convolutional layers, pooling layers, dropout layer, fully connected Dense layers, and output layer.

## CNN for MRI Image Classification

MRI image classification is a binary image classification problem where the goal is to detect the presence of a tumor. Key aspects include:

- Image preprocessing such as resizing, normalization, and grayscale conversion.
- Label encoding of categorical class labels.
- Use of convolution and pooling layers for spatial feature extraction.
- Evaluation using accuracy as the primary performance metric.

CNNs are particularly suitable for MRI datasets because they preserve spatial relationships in images and can learn complex visual patterns relevant to medical diagnosis.

## Algorithm

1. Import required libraries such as NumPy, Pandas, OpenCV, TensorFlow, and Keras.
2. Load MRI images from tumor and non-tumor directories and assign corresponding labels.
3. Resize images to a fixed dimension and convert them to grayscale.
4. Normalize pixel values to the range 0-1.
5. Convert image and label data into NumPy arrays.
6. Encode class labels using label encoding.
7. Reshape image data to match CNN input format.
8. Split the dataset into training and testing sets.
9. Build a Sequential CNN model with convolution, pooling, dropout, and dense layers.
10. Compile the model using Adam optimizer and categorical loss function.
11. Train the CNN model for a fixed number of epochs with validation data.
12. Predict class labels for test images.
13. Evaluate the model using accuracy on the test dataset.

## Code

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import os
from tensorflow import keras
from tensorflow.keras import layers
from tensorflow.keras import layers, models
import cv2
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import LabelEncoder

base_path = "/kaggle/input/mri-images/MRI/Training"
data = []

tumor_path = os.path.join(base_path, "tumor")
for filename in os.listdir(tumor_path):
    filepath = os.path.join(tumor_path, filename)
    data.append({"filepath": filepath, "label": "tumor"})

notumor_path = os.path.join(base_path, "notumor")
for filename in os.listdir(notumor_path):
    filepath = os.path.join(notumor_path, filename)
    data.append({"filepath": filepath, "label": "notumor"})

df = pd.DataFrame(data)

IMG_HEIGHT = 128
IMG_WIDTH = 128
CHANNELS = 1

images = []
labels = []

for index, row in df.iterrows():
    try:
        img = cv2.imread(row["filepath"], cv2.IMREAD_GRAYSCALE)
        img = cv2.resize(img, (IMG_WIDTH, IMG_HEIGHT))
        img = img / 255.0
        images.append(img)
        labels.append(row["label"])
    except Exception as e:
        print(f"Error loading image {row['filepath']}: {e}")

X = np.array(images)
y = np.array(labels)
X = X.reshape(-1, IMG_HEIGHT, IMG_WIDTH, CHANNELS)

label_encoder = LabelEncoder()
y_encoded = label_encoder.fit_transform(y)

plt.figure(figsize=(4, 4))
plt.imshow(X[0].reshape(IMG_HEIGHT, IMG_WIDTH), cmap="gray")
plt.title(f"Label: {label_encoder.inverse_transform([y_encoded[0]])[0]}")
plt.axis("off")
plt.show()

X_train, X_test, y_train, y_test = train_test_split(
    X, y_encoded, test_size=0.2, random_state=42, stratify=y_encoded
)

num_classes = len(label_encoder.classes_)

model = models.Sequential(
    [
        layers.Conv2D(
            32,
            (3, 3),
            activation="relu",
            input_shape=(IMG_HEIGHT, IMG_WIDTH, CHANNELS),
        ),
        layers.MaxPooling2D(pool_size=(2, 2)),
        layers.Conv2D(64, (5, 5), activation="relu"),
        layers.MaxPooling2D(pool_size=(2, 2)),
        layers.Dropout(0.25),
        layers.Flatten(),
        layers.Dense(64, activation="relu"),
        layers.Dense(num_classes, activation="sigmoid"),
    ]
)

model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"],
)

model.summary()
history = model.fit(X_train, y_train, epochs=10, validation_split=0.1)

y_pred_raw = model.predict(X_test)
y_pred = np.argmax(y_pred_raw, axis=1)

loss, accuracy_eval = model.evaluate(X_test, y_test)
print(f"\nModel evaluation results:")
print(f"Test Loss: {loss:.4f}")
print(f"Test Accuracy: {accuracy_eval:.4f}")
```
