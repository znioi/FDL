# Experiment 10

## Aim

Implementation of transfer learning using the pre-trained model VGG16 on image dataset in Python.

## Description

Convolutional Neural Networks (CNNs) have proven to be highly effective for image classification tasks due to their ability to automatically learn spatial features such as edges, textures, and object parts. However, training deep CNNs from scratch requires large datasets and high computational resources. To address this, transfer learning is widely used, where a pre-trained model is adapted to a new task.

In this experiment, we utilize the VGG16 architecture, a deep CNN model pre-trained on the ImageNet dataset, to perform image classification on the CIFAR-10 dataset. CIFAR-10 consists of 60,000 small color images categorized into 10 classes such as airplane, automobile, bird, cat, etc. Since VGG16 expects larger input sizes, the images are resized to 64x64 and normalized to improve training efficiency.

The pre-trained VGG16 model is loaded without its top classification layers, and all its convolutional layers are initially frozen to retain the learned feature representations. A custom classifier is then built on top using fully connected Dense layers and Dropout layers to reduce overfitting. This phase is known as feature extraction, where only the newly added layers are trained.

To further improve performance, a fine-tuning step is applied by unfreezing the top layers of the VGG16 model, allowing the network to adapt high-level features specifically to the CIFAR-10 dataset. The model is then recompiled with a lower learning rate to ensure stable updates. Finally, the trained model is evaluated on test data, and performance metrics such as accuracy and loss are visualized. Predictions on sample images are also displayed to qualitatively assess the model's classification capability.

## Algorithm

1. Import required libraries for data processing, visualization, and deep learning.
2. Load CIFAR-10 dataset into training and testing sets.
3. Resize images, normalize pixel values, and apply one-hot encoding to labels.
4. Load VGG16 without top layers and freeze its weights.
5. Add Flatten, Dense, and Dropout layers to create a custom classifier.
6. Compile using Adam optimizer with categorical cross-entropy loss.
7. Train the model on training data using feature extraction.
8. Unfreeze top layers of VGG16 and recompile with a low learning rate.
9. Train again to fine-tune deeper layers.
10. Evaluate performance on test data and compute accuracy.
11. Plot accuracy and loss graphs for training and validation.
12. Predict and display results on sample test images.

## Code

```python
import numpy as np
import matplotlib.pyplot as plt
import tensorflow as tf
from tensorflow.keras.applications import VGG16
from tensorflow.keras.layers import Dense, Flatten, Dropout
from tensorflow.keras.models import Model
from tensorflow.keras.optimizers import Adam
from tensorflow.keras.datasets import cifar10
from tensorflow.keras.utils import to_categorical

# Load and preprocess CIFAR-10 dataset.
(x_train, y_train), (x_test, y_test) = cifar10.load_data()

# Resize to 64x64. VGG16 default is 224x224, but 64 is faster on Kaggle.
x_train = tf.image.resize(x_train, [64, 64]).numpy() / 255.0
x_test = tf.image.resize(x_test, [64, 64]).numpy() / 255.0

y_train = to_categorical(y_train, 10)
y_test = to_categorical(y_test, 10)

class_names = [
    "airplane",
    "automobile",
    "bird",
    "cat",
    "deer",
    "dog",
    "frog",
    "horse",
    "ship",
    "truck",
]

# Load VGG16 base pre-trained on ImageNet without top classifier.
base_model = VGG16(weights="imagenet", include_top=False, input_shape=(64, 64, 3))
base_model.trainable = False

# Build custom classifier on top.
x = base_model.output
x = Flatten()(x)
x = Dense(256, activation="relu")(x)
x = Dropout(0.5)(x)
x = Dense(128, activation="relu")(x)
x = Dropout(0.3)(x)
output = Dense(10, activation="softmax")(x)

model = Model(inputs=base_model.input, outputs=output)

model.compile(
    optimizer=Adam(learning_rate=0.001),
    loss="categorical_crossentropy",
    metrics=["accuracy"],
)

model.summary()

# Train the model in feature extraction phase.
history = model.fit(
    x_train,
    y_train,
    epochs=10,
    batch_size=64,
    validation_split=0.1,
    verbose=1,
)

# Fine-tuning: unfreeze last 4 layers of VGG16 block5.
base_model.trainable = True
for layer in base_model.layers[:-4]:
    layer.trainable = False

model.compile(
    optimizer=Adam(learning_rate=1e-5),
    loss="categorical_crossentropy",
    metrics=["accuracy"],
)

history_ft = model.fit(
    x_train,
    y_train,
    epochs=10,
    batch_size=64,
    validation_split=0.1,
    verbose=1,
)

# Evaluate.
loss, acc = model.evaluate(x_test, y_test, verbose=0)
print(f"\nTest Accuracy: {acc * 100:.2f}%")

# Plot training curves.
fig, axes = plt.subplots(1, 2, figsize=(12, 4))
all_acc = history.history["accuracy"] + history_ft.history["accuracy"]
all_val = history.history["val_accuracy"] + history_ft.history["val_accuracy"]
all_loss = history.history["loss"] + history_ft.history["loss"]
all_vloss = history.history["val_loss"] + history_ft.history["val_loss"]

axes[0].plot(all_acc, label="Train Accuracy")
axes[0].plot(all_val, label="Val Accuracy")
axes[0].set_title("VGG16 - Accuracy")
axes[0].legend()

axes[1].plot(all_loss, label="Train Loss")
axes[1].plot(all_vloss, label="Val Loss")
axes[1].set_title("VGG16 - Loss")
axes[1].legend()

plt.tight_layout()
plt.show()

# Predictions on a few test samples.
preds = model.predict(x_test[:10])
fig, axes = plt.subplots(2, 5, figsize=(14, 5))

for i, ax in enumerate(axes.flat):
    ax.imshow(x_test[i])
    pred_label = class_names[np.argmax(preds[i])]
    true_label = class_names[np.argmax(y_test[i])]
    ax.set_title(
        f"Pred: {pred_label}\nTrue: {true_label}",
        color="green" if pred_label == true_label else "red",
        fontsize=9,
    )
    ax.axis("off")

plt.suptitle("VGG16 Predictions", fontsize=13)
plt.tight_layout()
plt.show()
```

## Output

The program displays the VGG16 model summary, trains the model in feature extraction and fine-tuning phases, prints test accuracy, plots accuracy and loss curves, and displays sample CIFAR-10 predictions.
