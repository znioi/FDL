# Experiment 2A

## Aim

Implementation of ANN model for regression problem in Python.

## Description

An Artificial Neural Network (ANN) consists of three main components:

- **Input layer:** Receives the feature values.
- **Hidden layers:** Perform nonlinear transformations using weighted connections and activation functions.
- **Output layer:** Produces the predicted continuous value.

For regression tasks:

- The output layer typically contains a single neuron.
- No activation function or a linear activation is used in the output layer.
- Loss functions such as Mean Squared Error (MSE) or Mean Absolute Error (MAE) are commonly used.

Unlike linear regression, ANNs can model complex, nonlinear relationships between variables, making them suitable for real-world datasets with intricate feature interactions.

A regression problem aims to predict a continuous output variable based on one or more input features. Common examples include predicting house prices, temperature, stock values, or energy consumption.

Key characteristics of regression problems include:

- Continuous target variable.
- Evaluation using metrics such as MSE, RMSE, MAE, and R2 score.
- Sensitivity to feature scaling, making normalization or standardization essential.

Regression models must generalize well to unseen data, avoiding both underfitting and overfitting.

## Algorithm

1. Import required TensorFlow and Scikit-learn libraries.
2. Load the California Housing dataset.
3. Split the data into training and testing sets.
4. Normalize input features using StandardScaler.
5. Construct a Sequential ANN model with Dense layers.
6. Use ReLU activation in hidden layers and linear output layer.
7. Compile the model using Adam optimizer and MSE loss.
8. Train the model for a fixed number of epochs.
9. Evaluate the model on test data.
10. Predict outputs and calculate MSE, MAE, and R2 score.

## Code

```python
import tensorflow as tf
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import fetch_california_housing
from tensorflow.keras import layers, datasets, models
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

regression_data = fetch_california_housing()
X = pd.DataFrame(regression_data.data, columns=regression_data.feature_names)
y = pd.DataFrame(regression_data.target, columns=["target"])

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=1
)

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

model = models.Sequential(
    layers=[
        layers.Dense(128, activation="relu", input_shape=(X_train.shape[1],)),
        layers.Dense(64, activation="relu"),
        layers.Dense(32, activation="relu"),
        layers.Dense(1),
    ]
)

model.summary()
model.compile(optimizer="adam", loss="mse", metrics=["mae"])
model.fit(X_train, y_train, epochs=50, batch_size=32, verbose=1)
model.evaluate(X_test, y_test)

y_pred = model.predict(X_test)
mse = mean_squared_error(y_test, y_pred)
mae = mean_absolute_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)

print("Mean Squared Error: ", mse)
print("Mean Absolute Error: ", mae)
print("R2 Score: ", r2)
```

## Output

The model displays training progress for 50 epochs, evaluates loss and MAE on the test dataset, and prints:

- Mean Squared Error
- Mean Absolute Error
- R2 Score

## Learning Outcomes

- Understood the architecture of an ANN for regression problems.
- Learned how to load and preprocess the California Housing dataset.
- Applied feature scaling using StandardScaler.
- Built and trained a Sequential ANN model using TensorFlow/Keras.
- Evaluated regression performance using MSE, MAE, and R2 score.

# Experiment 2B

## Aim

Implementation of ANN model for classification problem in Python.

## Description

An Artificial Neural Network (ANN) for classification is designed to assign input data to one of several predefined classes. Similar to regression, an ANN used for classification consists of three main components:

- **Input layer:** Receives the feature values of the dataset.
- **Hidden layers:** Perform nonlinear transformations using weighted connections and activation functions such as ReLU or sigmoid, enabling the network to learn complex patterns.
- **Output layer:** Produces the predicted class probabilities or class labels.

For classification tasks:

- The output layer contains one neuron for binary classification or multiple neurons for multi-class classification.
- Activation functions such as sigmoid for binary classification or softmax for multi-class classification are used in the output layer.
- Loss functions such as Binary Cross-Entropy or Categorical Cross-Entropy are commonly employed.

Unlike traditional classifiers, ANNs can model highly nonlinear decision boundaries, making them effective for complex classification problems.

## Algorithm

1. Import required TensorFlow and Scikit-learn libraries.
2. Load the Breast Cancer dataset.
3. Separate the dataset into input features X and target labels y.
4. Split the data into training and testing sets.
5. Normalize input features using StandardScaler.
6. Construct a Sequential ANN model with fully connected Dense layers.
7. Use ReLU activation in hidden layers and sigmoid activation in the output layer.
8. Compile the model using Adam optimizer and binary cross-entropy loss.
9. Train the model for a fixed number of epochs and batch size.
10. Evaluate the trained model on the test dataset.
11. Predict class labels for the test data.
12. Compute accuracy, confusion matrix, and classification report.

## Code

```python
import tensorflow as tf
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import load_breast_cancer
from tensorflow.keras import layers, datasets, models
from sklearn.metrics import accuracy_score, confusion_matrix, classification_report

data_classification = load_breast_cancer()
X = pd.DataFrame(data_classification.data, columns=data_classification.feature_names)
y = pd.DataFrame(data_classification.target, columns=["target"])

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=1
)

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

y_train.value_counts()

classification_model = models.Sequential(
    layers=[
        layers.Dense(128, activation="relu", input_shape=(X_train.shape[1],)),
        layers.Dense(64, activation="relu"),
        layers.Dense(32, activation="relu"),
        layers.Dense(1, activation="sigmoid"),
    ]
)

classification_model.compile(
    optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"]
)
classification_model.fit(X_train, y_train, epochs=10, batch_size=32, verbose=1)
classification_model.evaluate(X_test, y_test)

y_pred = classification_model.predict(X_test)
y_pred = np.round(y_pred)

acc = accuracy_score(y_test, y_pred)
conf_matrix = confusion_matrix(y_test, y_pred)
class_report = classification_report(y_test, y_pred)

print(f"Accuracy: {acc}")
print(f"Confusion Matrix: \n{conf_matrix}")
print(f"Classification Report: \n {class_report}")
```

## Output

The model displays training progress for 10 epochs, evaluates loss and accuracy on the test dataset, and prints:

- Accuracy
- Confusion Matrix
- Classification Report

## Learning Outcomes

- Understood the structure of an ANN for binary classification.
- Learned how to load and preprocess the Breast Cancer dataset.
- Applied standardization to improve neural network training.
- Built and trained a classification model using TensorFlow/Keras.
- Evaluated classification performance using accuracy, confusion matrix, and classification report.
