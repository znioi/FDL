## Aim

Implementation of Autoencoders for dimensionality reduction in Python.

## Description

Autoencoders are a class of Artificial Neural Networks (ANNs) used for unsupervised learning and dimensionality reduction. They are designed to learn efficient representations of input data by compressing the data into a lower-dimensional space and then reconstructing it back to its original form.

Unlike traditional dimensionality reduction techniques such as Principal Component Analysis (PCA), autoencoders can capture non-linear relationships within the data using multiple hidden layers and activation functions.

An autoencoder consists of three main components: encoder, bottleneck layer, and decoder.

The encoder compresses the high-dimensional input data into a lower-dimensional latent representation. The bottleneck layer contains the compressed features that represent the most important information of the input data. The decoder reconstructs the original input from this compressed representation.

Autoencoders are particularly useful when dealing with high-dimensional datasets such as images, text data, or sensor data, where reducing the number of features helps improve computational efficiency while retaining essential information.

## Autoencoder for Dimensionality Reduction

Dimensionality reduction is the process of reducing the number of input variables while preserving important structural information. In this experiment, an autoencoder model is implemented using Python and TensorFlow/Keras to reduce the dimensionality of the dataset.

Autoencoders are suitable for dimensionality reduction because they automatically learn meaningful compressed representations without requiring labeled data.

## Algorithm

1. Import required libraries such as NumPy, Pandas, TensorFlow, and Keras.
2. Load the dataset and perform preprocessing steps such as normalization.
3. Convert the dataset into NumPy arrays.
4. Split the dataset into training and testing sets.
5. Define the encoder using Dense layers with gradually decreasing neurons.
6. Add a bottleneck layer with reduced dimensionality.
7. Define the decoder using Dense layers with increasing neurons to reconstruct the input.
8. Combine encoder and decoder to build the Autoencoder model.
9. Compile the model using Adam optimizer and Mean Squared Error loss function.
10. Train the model using the input data as both input and target output.
11. Obtain compressed features from the encoder part of the model.
12. Evaluate reconstruction performance on test data.

## Code

```python
import numpy as np
from keras.layers import Input, Dense
from keras.models import Model
import matplotlib.pyplot as plt

np.random.seed(42)
data = np.random.rand(1000, 20)

input_dim = data.shape[1]
encoding_dim = 10

input_layer = Input(shape=(input_dim,))
encoder_layer = Dense(encoding_dim, activation="relu")(input_layer)
decoder_layer = Dense(input_dim, activation="sigmoid")(encoder_layer)

autoencoder = Model(inputs=input_layer, outputs=decoder_layer)
autoencoder.compile(optimizer="adam", loss="mean_squared_error")

history = autoencoder.fit(
    data,
    data,
    epochs=50,
    batch_size=32,
    shuffle=True,
    validation_split=0.2,
)

plt.title("Autoencoder Model Loss")
plt.plot(history.history["loss"])
plt.ylabel("loss")
plt.xlabel("epoch")
plt.legend(["training", "validation"], loc="upper right")
plt.show()

encoder = Model(inputs=input_layer, outputs=encoder_layer)
encoded_data = encoder.predict(data)
reconstructed_data = autoencoder.predict(data)

num_samples_to_plot = 5
plt.figure(figsize=(15, 6))

for i in range(num_samples_to_plot):
    plt.subplot(2, num_samples_to_plot, i + 1)
    plt.imshow(data[i].reshape(4, 5), cmap="gray")
    plt.title("Original")
    plt.axis("off")

    plt.subplot(2, num_samples_to_plot, i + num_samples_to_plot + 1)
    plt.imshow(reconstructed_data[i].reshape(4, 5), cmap="gray")
    plt.title("Reconstructed")
    plt.axis("off")

plt.show()
```
